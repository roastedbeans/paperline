# MDPI LaTeX Template

Generic MDPI-style starter using the standard `article` class. MDPI publishes journal-specific class files (e.g., `Definitions/mdpi.cls`) on each journal's "Instructions for Authors" page, for example:

- *Sensors*: https://www.mdpi.com/journal/sensors/instructions
- *Electronics*: https://www.mdpi.com/journal/electronics/instructions
- *Applied Sciences*: https://www.mdpi.com/journal/applsci/instructions

For a real submission, download the journal-specific package, drop the class file next to `main.tex`, and change the `\documentclass` line accordingly. The current skeleton compiles without the MDPI class so drafting can begin immediately.

## Files

- `main.tex` — manuscript skeleton
- `references.bib` — empty bibliography, populate from `references/` markdown notes
