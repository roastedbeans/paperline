# EasyChair LaTeX Template

Minimal starter using the `easychair` class for workshop and conference proceedings hosted on EasyChair.

The `easychair` class is bundled with most TeX distributions. If your distribution does not include it, download `easychair.cls` from the EasyChair Smart Authoring page and place it next to `main.tex`.

## Files

- `main.tex` — manuscript skeleton
- `references.bib` — empty bibliography, populate from `references/` markdown notes
