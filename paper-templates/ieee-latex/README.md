# IEEE LaTeX Template

Minimal `IEEEtran` starter for an IEEE conference paper. For transactions, change the document class option:

- Conference: `\documentclass[conference]{IEEEtran}`
- Journal / Transactions: `\documentclass[journal]{IEEEtran}`

The `IEEEtran` class is bundled with most TeX distributions. If your distribution does not include it, download from the IEEE author resources page.

## Files

- `main.tex` — manuscript skeleton
- `references.bib` — empty bibliography, populate from `references/` markdown notes
