# References

One Markdown file per paper. Each file collects every reference the paper cites, with metadata pulled from OpenAlex (when a DOI is available) and bib fallbacks otherwise.

## Filename convention

`{paper-slug}.md`, where `{paper-slug}` is the directory name of the paper under `../papers-latex/` with any leading `{template}-latex_` prefix stripped:

- `papers-latex/easychair-latex_simbox-detection` → `references/simbox-detection.md`
- `papers-latex/tsp_survey` → `references/tsp_survey.md`

This matches the experiment-folder convention in `../experiments/`, so paper, references, and experiment artefacts share the same slug.

## File format

Each file is a single document with one `##` section per cited reference. Sections are sorted alphabetically by cite key. Header lines record total / with-abstract / no-DOI counts.

```markdown
# References, {paper-slug}

Source paper: `papers-latex/{dir}/`
Generated by `paper-pipeline/scripts/import_references.py` on YYYY-MM-DD.

Total cited keys: N. With abstracts: M. Without DOI: K.

---

## `{cite_key}`

- **Title:** ...
- **Authors:** ...
- **Year:** ...
- **Venue:** ...
- **DOI:** [10.x/y](https://doi.org/10.x/y)
- **arXiv:** ...
- **URL:** <...>

### Abstract

...

### Notes

_(blank, fill in manually)_

---
```

## Generating or refreshing

Run the importer for any paper directory:

```bash
python3 paper-pipeline/scripts/import_references.py paper-pipeline/papers-latex/{paper-dir}
```

The script overwrites the output file, so manual edits inside the `### Notes` blocks are lost on re-import. Move long-form notes into a separate file under the same slug if persistence matters (e.g., `references/{slug}-notes.md`).
